Déploiement GitHub Pages

Suivez ces étapes simples pour mettre votre site en ligne

Important : Le dépôt est actuellement privé. GitHub Pages nécessite un dépôt public (plan gratuit) pour fonctionner. Suivez l'étape 1 ci-dessous.

1 Rendre le dépôt PUBLIC

Pour que GitHub Pages fonctionne avec un plan gratuit, le dépôt doit être visible publiquement.

Comment faire :

  1. Allez dans les paramètres du dépôt
  2. Descendez jusqu'à "Danger Zone" (tout en bas)
  3. Cliquez "Change repository visibility"
  4. Sélectionnez "Public" et confirmez
Ouvrir les paramètres du dépôt

2 Activer GitHub Pages

Dans les paramètres du dépôt, activez le déploiement depuis la branche main.

Configuration :

  • Source : Deploy from a branch
  • Branch : main
  • Folder : / (root)
Ouvrir GitHub Pages

3 Attendre le déploiement

GitHub va construire et déployer votre site automatiquement. Cela prend généralement 1 à 3 minutes.

Vous recevrez une notification par email quand le déploiement sera terminé.

Alternative : GitHub Actions

Pour un déploiement automatique à chaque modification, ajoutez ce workflow :

Chemin : .github/workflows/deploy-pages.yml

name: Deploy to GitHub Pages on: push: branches: ["main"] workflow_dispatch: permissions: contents: read pages: write id-token: write jobs: deploy: environment: name: github-pages url: ${{ steps.deployment.outputs.page_url }} runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: actions/configure-pages@v4 - uses: actions/upload-pages-artifact@v3 with: path: '.' - name: Deploy to GitHub Pages id: deployment uses: actions/deploy-pages@v4
